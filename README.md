# DBMS Project – IBM DB2 with Python

## Project Description

This project demonstrates how to use the **IBM DB2** database system through **Python** and **Jupyter Notebook**. It walks through:

- Installing and running DB2 via Docker  
- Connecting to DB2 from Python using `ibm_db`  
- Creating tables and performing CRUD operations  
- Writing SQL queries (including aggregations and subqueries)  
- Measuring query performance  
- Comparing DB2 with other relational databases  

---

### System Requirements
